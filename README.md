# Aposte em Você

Site gratuito, aberto por link no celular, para adultos afetados por apostas. A pessoa:
- responde a uma entrevista;
- se quiser, carrega extratos bancários em PDF;
- confere uma a uma as movimentações ligadas a apostas;
- baixa documentos para levar a um psicólogo, a um advogado ou ao banco.

**Tudo acontece no aparelho: nada do que a pessoa informa sai do celular.**
